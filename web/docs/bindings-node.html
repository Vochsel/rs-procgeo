Node.js API

Server-side usage through the WebAssembly package.

Installation

npm install @vochsel/procgeo-js

ProcGeo uses the same WebAssembly package in both browsers and Node.js. There are no platform-specific native addon binaries to install.

Initialization

The Node.js package is ESM and must be initialized once before use. 

import init, * as pg from '@vochsel/procgeo-js';

await init();
Typed SOP helpers use camelCase parameter keys in JavaScript. Registry calls such as executeSop accept snake_case keys because they map directly to the Rust registry serializer.

Geometry Object

All creation and manipulation functions return a Geometry object with the same API as the browser/WebAssembly binding.

Property / MethodReturnsDescription
numPoints number Number of points (getter).
numPrims number Number of primitives (getter).
numVertices number Number of vertices (getter).
pointPos(index) Float32Array Point position as [x, y, z].
boundingBox() { min: Float32Array, max: Float32Array } Axis-aligned bounding box.
getPositions() Float32Array Interleaved point positions for GPU upload.
getTriangleIndices() Uint32Array Fan-triangulated primitive indices.
toObj() string Export geometry as Wavefront OBJ text.
toGlb() Uint8Array Export geometry as binary glTF.

Common Pattern

Build geometry synchronously in Rust-backed WASM, then write the exported bytes or text with Node's filesystem APIs: 

import { writeFile } from 'node:fs/promises';
import init, * as pg from '@vochsel/procgeo-js';

await init();

const base = pg.createBox({ size: [2, 2, 2] });
const smooth = pg.smooth(
  pg.subdivide(base, { depth: 2, mode: 'catmullClark' }),
  { iterations: 3, strength: 0.5 }
);
const geo = pg.computeNormals(smooth);

console.log(`Points: ${geo.numPoints}`);
console.log(`Prims: ${geo.numPrims}`);

await writeFile('output.obj', geo.toObj());
await writeFile('output.glb', geo.toGlb());

Registry Dispatch

New SOPs and COPs are available automatically through the registry helpers. 

const names = pg.listSops();
const geo = pg.executeSopCreate('box', { size: [1, 1, 1] });
const moved = pg.executeSop('transform', geo, { translate: [5, 0, 0] });
ProcGeo's Node.js API now mirrors the WebAssembly/browser binding. If you were previously using native addon helpers such as writeObj(..., path), replace them with toObj() / toGlb() plus fs.writeFile.
