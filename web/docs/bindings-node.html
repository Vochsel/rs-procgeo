Node.js API

Server-side usage via napi-rs bindings.

Installation

npm install @procgeo/core

The package ships pre-built native binaries for Linux (x64, arm64), macOS (x64, arm64), and Windows (x64). No Rust toolchain required at install time. 

const pg = require('@procgeo/core');
// or
import * as pg from '@procgeo/core';

Geometry Object

All creation and manipulation functions return a Geometry object with the following properties and methods:

Property / MethodReturnsDescription
numPoints number Number of points (getter).
numPrims number Number of primitives (getter).
numVertices number Number of vertices (getter).
pointPos(index) number[] Position of a point as [x, y, z].
boundingBox() { min: number[], max: number[] } Axis-aligned bounding box.

Creation Functions

All creation functions accept an optional params object. Param keys use snake_case to match the Rust convention. Omitted fields use Houdini-style defaults.

FunctionParamsDescription
createBox(params?) size: [x,y,z], center: [x,y,z] Axis-aligned box. Default size [1,1,1].
createGrid(params?) rows, cols, size_x, size_y, center: [x,y,z] Quad grid. Default 10x10, size 10x10.
createSphere(params?) radius, rows, cols, center: [x,y,z] UV sphere. Default radius 0.5, 12 rows, 24 cols.
createLine(params?) origin: [x,y,z], direction: [x,y,z], length, points Open polyline. Default length 1, 2 points.
createCircle(params?) radius, divisions, center: [x,y,z] Circle polygon. Default radius 1, 40 divisions.
createTube(params?) radius_bottom, radius_top, height, cols, rows, center: [x,y,z] Cylinder/cone. Default radii 0.5, height 1.
createTorus(params?) radius_outer, radius_inner, rows, cols, center: [x,y,z] Torus. Default outer 1.0, inner 0.3.
revolve(geo, params?) origin: [x,y,z], axis: [x,y,z], divisions, start_angle, end_angle, end_caps Revolve a profile curve around an axis.
createMetaball(params?) balls: [{center, radius, weight}], threshold, kernel, resolution Metaball isosurface.

Manipulation Functions

All manipulation functions take a Geometry as the first argument and return a new Geometry. Input geometry is never mutated.

FunctionParamsDescription
transform(geo, params?) translate: [x,y,z], rotate: [x,y,z], scale: [x,y,z], pivot: [x,y,z] Translate, rotate, and scale.
computeNormals(geo) — Area-weighted vertex normals.
merge(geometries) Array of Geometry Merge multiple geometries into one.
subdivide(geo, params?) depth Subdivide faces. Default depth 1.
scatter(geo, params?) count, seed Random points on surface. Default 100 points.
copyToPoints(source, target) — Instance source at each target point.
polyExtrude(geo, params?) distance, inset, output_front, output_side Extrude faces. Default distance 1.
smooth(geo, params?) iterations, strength Laplacian smooth. Default 1 iter, 0.5 strength.
clip(geo, params?) origin: [x,y,z], normal: [x,y,z], keep_above Clip by plane. Default clips above Y=0.
reverse(geo) — Flip polygon winding order.
resample(geo, params?) length, max_segments Resample curves. Default length 0.1.
sort(geo, params?) seed Randomize point/prim order.
fuse(geo, params?) distance Merge coincident points. Default 0.001.
connectivity(geo, params?) attrib_name Label connected components. Default attrib "class".
color(geo, params?) color: [r,g,b] Set uniform colour. Default white.
enumerateAttrib(geo, params?) name, start Add sequential index attribute. Default "index" from 0.
measure(geo, params?) attrib_name Compute area per primitive.

I/O Functions

Write geometry to disk in OBJ or GLB format. The format is determined by the function you call, not the file extension.

FunctionDescription
writeObj(geo, path) Write geometry as Wavefront OBJ.
writeGlb(geo, path) Write geometry as binary glTF (GLB).

Example

A complete Node.js script that generates procedural geometry, processes it through multiple SOPs, and exports to disk: 

const pg = require('@procgeo/core');

// Generate a box and subdivide it
const box = pg.createBox({ size: [2, 2, 2] });
const subdiv = pg.subdivide(box, { depth: 2 });

// Smooth the subdivided box
const smoothed = pg.smooth(subdiv, {
  iterations: 3,
  strength: 0.5
});

// Compute normals for shading
const withNormals = pg.computeNormals(smoothed);

// Scatter points on the surface
const scattered = pg.scatter(withNormals, {
  count: 200,
  seed: 42
});

// Create a small sphere to instance at each scattered point
const stamp = pg.createSphere({ radius: 0.05 });
const instances = pg.copyToPoints(stamp, scattered);

// Merge the smoothed box and the scattered instances
const final = pg.merge([withNormals, instances]);

// Query geometry info
console.log(`Points: ${final.numPoints}`);
console.log(`Prims:  ${final.numPrims}`);
console.log(`BBox:   ${JSON.stringify(final.boundingBox())}`);

// Export to disk
pg.writeObj(final, 'output.obj');
pg.writeGlb(final, 'output.glb');

console.log('Done!');
All SOP functions are synchronous. They execute the full Rust geometry pipeline on the main thread and return the result immediately. For heavy workloads, consider running the pipeline in a Worker thread.
