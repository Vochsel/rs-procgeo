Rust API

Native Rust usage via the procgeo umbrella crate.

Installation

Add ProcGeo to your project with Cargo:

cargo add procgeo

Or add it directly to your Cargo.toml:

[dependencies]
procgeo = "0.1"

By default, all SOP categories and I/O formats are enabled. To reduce compile time and binary size, disable defaults and opt in to only the features you need: 

[dependencies]
procgeo = { version = "0.1", default-features = false, features = ["creation", "transform", "obj"] }

The Prelude

The prelude re-exports all core types, handles, traits, and every SOP enabled by your feature selection. A single glob import gives you everything you need: 

use procgeo::prelude::*;

This brings into scope:

  • Geometry, PointHandle, VertexHandle, PrimHandle
  • AttribClass, AttribHandle<T>
  • BBox, PolyType
  • Vec2, Vec3, Vec4, Mat3, Mat4, Quat (from glam)
  • Sop, GeometryExt, generate()
  • All enabled SOP structs and their *Params types

Creating Geometry

Start with an empty geometry and add points and faces manually: 

use procgeo::prelude::*;
use glam::Vec3;

// Empty geometry
let mut geo = Geometry::new();

// Pre-allocate when you know the approximate size
let mut geo = Geometry::with_capacity(1000, 500);

// Add points
let p0 = geo.add_point(Vec3::new(0.0, 0.0, 0.0));
let p1 = geo.add_point(Vec3::new(1.0, 0.0, 0.0));
let p2 = geo.add_point(Vec3::new(1.0, 1.0, 0.0));
let p3 = geo.add_point(Vec3::new(0.0, 1.0, 0.0));

// Add a closed face (polygon)
let face = geo.add_face(&[p0, p1, p2, p3]);

// Add an open polyline
let line = geo.add_polyline(&[p0, p1, p2]);

// Query counts
assert_eq!(geo.num_points(), 4);
assert_eq!(geo.num_prims(), 2);

Using SOPs

SOPs are stateless operators. There are three patterns for invoking them, depending on the number of inputs the SOP requires.

Pattern 1: Generators (0 inputs)

Use the generate() helper for SOPs that create geometry from scratch:

use procgeo::prelude::*;

let box_geo = generate(&BoxSop, &BoxParams {
    size: Vec3::new(2.0, 1.0, 1.0),
    center: Vec3::ZERO,
})?;

let sphere = generate(&SphereSop, &SphereParams {
    radius: Vec3::splat(0.5),
    rows: 16,
    cols: 32,
    ..Default::default()
})?;

let grid = generate(&GridSop, &GridParams::default())?;

Pattern 2: Chaining with .apply() (1 input)

The GeometryExt trait adds .apply() to Result<Geometry>, enabling fluent pipelines: 

use procgeo::prelude::*;

let result = generate(&BoxSop, &BoxParams {
    size: Vec3::splat(2.0),
    ..Default::default()
})?
.apply(&SubdivideSop, &SubdivideParams { depth: 2, ..Default::default() })?
.apply(&TransformSop, &TransformParams {
    translate: Vec3::new(0.0, 1.0, 0.0),
    ..Default::default()
})?
.apply(&NormalSop, &NormalParams::default())?;

Pattern 3: Multi-input SOPs (2+ inputs)

Call execute() directly on the SOP struct, passing an input slice: 

use procgeo::prelude::*;

let stamp = generate(&BoxSop, &BoxParams::default())?;
let points = generate(&GridSop, &GridParams {
    rows: 5, cols: 5, ..Default::default()
})?;

// Copy the box to every point on the grid
let result = CopyToPointsSop.execute(
    &[&stamp, &points],
    &CopyToPointsParams,
)?;

// Merge multiple geometries
let merged = MergeSop.execute(
    &[&stamp, &points, &result],
    &MergeParams,
)?;

Working with Attributes

Attributes are typed per-element data arrays. Use AttribHandle<T> for compile-time type safety — you cannot accidentally read an f32 attribute as a [f32; 3]. 

use procgeo::prelude::*;

let mut geo = generate(&BoxSop, &BoxParams::default())?;

// Create a point attribute
let temp_handle: AttribHandle<f32> = geo.create_attrib(
    AttribClass::Point,
    "temperature",
    0.0_f32,   // default value
)?;

// Set values per point
for i in 0..geo.num_points() {
    let pos = geo.point_pos(PointHandle::from_index(i));
    geo.set_attrib(&temp_handle, i, pos.y * 100.0)?;
}

// Read values back
let val: f32 = geo.get_attrib(&temp_handle, 0)?;

// Find an existing attribute by name
let found: AttribHandle<f32> = geo.find_attrib(
    AttribClass::Point,
    "temperature",
)?;

// Vector attributes (e.g. color, UVs)
let cd_handle: AttribHandle<[f32; 3]> = geo.create_attrib(
    AttribClass::Point,
    "Cd",
    [1.0, 1.0, 1.0],
)?;
geo.set_attrib(&cd_handle, 0, [1.0, 0.0, 0.0])?;

Working with Groups

Groups are named boolean selections backed by bitsets. They can target points, primitives, or vertices. 

use procgeo::prelude::*;

let mut geo = generate(&GridSop, &GridParams {
    rows: 10, cols: 10, ..Default::default()
})?;

// Create a point group
geo.create_group(AttribClass::Point, "selected")?;

// Add points to the group based on position
for i in 0..geo.num_points() {
    let pos = geo.point_pos(PointHandle::from_index(i));
    if pos.y > 0.0 {
        geo.set_group_membership(AttribClass::Point, "selected", i, true)?;
    }
}

// Query group membership
let is_member = geo.group_membership(AttribClass::Point, "selected", 0)?;

// Check group size
let count = geo.group_count(AttribClass::Point, "selected")?;

Feature Flags

Each SOP category and I/O format is a Cargo feature. The umbrella crate enables all features by default. Opt in selectively for smaller binaries: 

[dependencies]
procgeo = { version = "0.1", default-features = false, features = [
    "creation",      # Box, Grid, Line, Circle, Sphere, Tube, Torus
    "transform",     # Transform SOP
    "normals",       # Normal SOP
    "reshape",       # Subdivide, PolyExtrude, Smooth, Clip
    "topology",      # Sort, Fuse, Connectivity, Resample, Reverse
    "obj",           # Wavefront OBJ read/write

I/O

Read and write geometry files using the procgeo::io module. The format is detected automatically from the file extension. 

use procgeo::prelude::*;
use std::path::Path;

let geo = generate(&BoxSop, &BoxParams::default())?
    .apply(&SubdivideSop, &SubdivideParams { depth: 2, ..Default::default() })?
    .apply(&NormalSop, &NormalParams::default())?;

// Write to OBJ
procgeo::io::write_file(&geo, Path::new("output.obj"))?;

// Write to GLB (binary glTF)
procgeo::io::write_file(&geo, Path::new("output.glb"))?;

// Read geometry from a file
let loaded = procgeo::io::read_file(Path::new("model.obj"))?;

Full Example

A complete program that generates a procedural mesh, applies multiple SOPs, adds custom attributes, and exports to both OBJ and GLB: 

use procgeo::prelude::*;
use std::path::Path;

fn main() -> Result<(), SopError> {
    // Generate a sphere and process it
    let mut geo = generate(&SphereSop, &SphereParams {
        radius: Vec3::splat(1.0),
        rows: 16,
        cols: 32,
        ..Default::default()
    })?
    .apply(&SubdivideSop, &SubdivideParams { depth: 1, ..Default::default() })?
    .apply(&NormalSop, &NormalParams::default())?;

    // Add a color attribute based on height
    let cd = geo.create_attrib::<[f32; 3]>(
        AttribClass::Point, "Cd", [1.0, 1.0, 1.0],
    )?;
    let bbox = geo.bounding_box();
    for i in 0..geo.num_points() {
        let pos = geo.point_pos(PointHandle::from_index(i));
        let t = (pos.y - bbox.min.y) / bbox.size().y;
        geo.set_attrib(&cd, i, [t, 0.3, 1.0 - t])?;
    }

    // Export
    procgeo::io::write_file(&geo, Path::new("sphere.obj"))?;
    procgeo::io::write_file(&geo, Path::new("sphere.glb"))?;

    println!("Exported {} points, {} prims", geo.num_points(), geo.num_prims());
    Ok(())
}
