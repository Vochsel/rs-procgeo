Attributes

Typed per-element data storage — 4 classes, 10 storage types, semantic qualifiers.

Overview

Attributes are named, typed data arrays attached to geometry elements. Every attribute belongs to one of four classes (Point, Vertex, Primitive, Detail), has one of ten storage types (Int through String), and optionally carries a type qualifier that encodes semantic meaning. Attributes auto-resize when elements are added — new slots are filled with the attribute's default value.

Attribute Classes

The class determines which element the attribute is scoped to and how many values it holds.

ClassScopeExamples
Point One value per point Position offsets, normals (N), color (Cd), pscale
Vertex One value per vertex UVs (uv), vertex normals, tangents
Primitive One value per primitive Material ID (shop_materialpath), area, face normal
Detail One value per geometry (singleton) Title, frame number, global settings 
pub enum AttribClass {
    Point,
    Vertex,
    Primitive,
    Detail,
}

Storage Types

Each attribute stores a homogeneous array of one of the following types. The storage is enum-dispatched internally via AttribStorage.

TypeRust TypeDescription
Inti3232-bit signed integer
Int64i6464-bit signed integer
Floatf3232-bit float
Float64f6464-bit float
Vector2[f32; 2]2D vector (e.g. UVs)
Vector3[f32; 3]3D vector (e.g. normals, color)
Vector4[f32; 4]4D vector (e.g. quaternion, RGBA)
Matrix3[f32; 9]3x3 matrix (rotation, scale)
Matrix4[f32; 16]4x4 matrix (full transform)
StringStringText data (material paths, labels)

Type Qualifiers

Type qualifiers carry semantic meaning beyond the raw storage type. They do not change how data is stored, but they inform SOPs how to transform the data correctly. For example, normals transform with the inverse-transpose of the matrix (not the matrix itself), and colors should not be transformed at all.

QualifierMeaning
NoneNo special semantics (default)
PointPosition-like data — transforms with the full matrix
VectorDirection — transforms with the upper 3x3 (no translation)
NormalSurface normal — transforms with the inverse-transpose
ColorColor data — not affected by spatial transforms
QuaternionRotation quaternion — special composition rules
MatrixEmbedded matrix — transforms by concatenation
 
pub enum TypeQualifier {
    None,
    Point,
    Vector,
    Normal,
    Color,
    Quaternion,
    Matrix,
}

AttribHandle<T>

AttribHandle<T> provides compile-time type safety for attribute access. The phantom type parameter T ensures you cannot accidentally read a Vector3 attribute as a Float — the mismatch is caught at compile time, not at runtime. 

pub struct AttribHandle<T> {
    pub class: AttribClass,
    pub name:  String,
    _marker:   PhantomData<T>,
}

Full Example

use procgeo::prelude::*;
use glam::Vec3;

let mut geo = Geometry::new();
let p0 = geo.add_point(Vec3::ZERO);
let p1 = geo.add_point(Vec3::ONE);

// Create a color attribute with a white default
geo.add_attrib(
    AttribClass::Point,
    "Cd",
    AttribDefault::Vector3([1.0, 1.0, 1.0]),
    TypeQualifier::Color,
).unwrap();

// Get a typed handle — the [f32; 3] type is checked against storage
let handle: AttribHandle<[f32; 3]> =
    geo.find_attrib(AttribClass::Point, "Cd").unwrap();

// Read — both points have the default white color
let color = geo.get_attrib(&handle, p0.index()).unwrap();
assert_eq!(color, [1.0, 1.0, 1.0]);

// Write — set p1 to red
geo.set_attrib(&handle, p1.index(), [1.0, 0.0, 0.0]).unwrap();
assert_eq!(
    geo.get_attrib(&handle, p1.index()).unwrap(),
    [1.0, 0.0, 0.0]
);
Auto-resize: When you add points, vertices, or primitives, all attributes of the matching class are automatically resized and filled with their default value. You never need to manually resize attribute storage.

API Reference

MethodSignatureDescription
add_attrib fn add_attrib(&mut self, class, name, default, qualifier) -> Result<()> Create a new attribute with the given class, name, default value, and type qualifier. Fails if an attribute with the same class + name already exists.
find_attrib fn find_attrib<T>(&self, class, name) -> Result<AttribHandle<T>> Look up an attribute by class and name, returning a typed handle. Fails if not found or if T does not match the stored type.
get_attrib fn get_attrib<T>(&self, handle, index) -> Result<T> Read the value at the given element index through a typed handle.
set_attrib fn set_attrib<T>(&mut self, handle, index, value) -> Result<()> Write a value at the given element index through a typed handle.
delete fn delete(&mut self, class, name) -> bool Remove an attribute. Returns true if it existed. Called on the AttributeMap via geo.attributes_mut().delete(...).
rename fn rename(&mut self, class, old, new) -> Result<()> Rename an attribute. Fails if the old name is not found or the new name already exists. Called on the AttributeMap.
get_raw fn get_raw(&self, class, name) -> Option<&Attribute> Get an untyped reference to the raw Attribute struct (storage, default, qualifier). Called on the AttributeMap.
names fn names(&self, class) -> Vec<&str> List the names of all attributes for a given class. Called on the AttributeMap.
