Utility & Measure SOPs

SOPs for attributes, groups, measurement, and utility operations.

These SOPs handle metadata — creating and manipulating attributes, groups, and computed measurements. All take 1 input. For detailed coverage of the attribute and group systems, see the Attributes and Groups core pages.

Color & Labelling

ColorSop color

Inputs: 1

Assigns a uniform RGB color to all points by creating or updating a "Cd" point attribute with the Color type qualifier. Values are in the 0–1 range per channel.

ParameterTypeDefaultDescription
color[f32; 3][1.0, 1.0, 1.0]RGB color (0–1 range)
 
let red = geo.apply(&ColorSop, &ColorParams {
    color: [1.0, 0.2, 0.1],
})?;

EnumerateSop utility_sops

Inputs: 1

Creates a sequential integer attribute on each point, starting from start and incrementing by 1. Useful for debugging, ordering, or driving downstream lookups.

ParameterTypeDefaultDescription
nameString"index"Attribute name
starti320Starting value
 
let numbered = geo.apply(&EnumerateSop, &EnumerateParams {
    name: "id".into(),
    start: 1,
})?;

NullSop utility_sops

Inputs: 1

A pass-through that returns the input geometry unchanged. Useful as a named anchor point in SOP chains, a no-op placeholder during development, or a merge target that does nothing.

ParameterTypeDefaultDescription
No parameters
 
// Mark a named output point in the chain
let output = geo.apply(&NullSop, &NullParams::default())?;

Measurement

MeasureSop measure_sops

Inputs: 1

Computes geometric measurements (area, perimeter) for each primitive and stores them as primitive attributes. If attrib_name is empty, the default names "area" and "perimeter" are used.

ParameterTypeDefaultDescription
attrib_nameString""Optional custom attribute name
 
let measured = geo.apply(&MeasureSop, &MeasureParams::default())?;

Attribute SOPs

These SOPs create, remove, rename, and promote attributes on geometry. For a full guide to the attribute system — classes, typed handles, type qualifiers — see the Attributes core page.

CreateAttributeSop attributes

Inputs: 1

Creates a new typed attribute on the specified attribute class (point, vertex, primitive, or detail). If the attribute already exists, it is overwritten with the new default value. 

let geo = geo.apply(&CreateAttributeSop, &CreateAttributeParams {
    name: "density".into(),
    class: AttribClass::Point,
    default_value: AttribValue::Float(1.0),
    ..Default::default()
})?;

DeleteAttributeSop attributes

Inputs: 1

Removes an attribute by name and class. Returns an error if the attribute does not exist. 

let geo = geo.apply(&DeleteAttributeSop, &DeleteAttributeParams {
    name: "temp".into(),
    class: AttribClass::Point,
})?;

PromoteAttributeSop attributes

Inputs: 1

Changes the class of an attribute (e.g., point to primitive). Values are aggregated or distributed as needed during the conversion. 

let geo = geo.apply(&PromoteAttributeSop, &PromoteAttributeParams {
    name: "Cd".into(),
    from_class: AttribClass::Point,
    to_class: AttribClass::Primitive,
})?;

RenameAttributeSop attributes

Inputs: 1

Renames an attribute while preserving its data, type, and class. 

let geo = geo.apply(&RenameAttributeSop, &RenameAttributeParams {
    old_name: "Cd".into(),
    new_name: "color".into(),
    class: AttribClass::Point,
})?;

Group SOPs

These SOPs create and combine element groups. Groups are stored as compact bitsets and are the primary selection mechanism for downstream SOPs like Blast and Delete. See the Groups core page for the full API.

GroupCreateSop groups_sops

Inputs: 1

Creates a named element group on points or primitives. Elements can be added to the group by index range, bounding box, or expression. 

let geo = geo.apply(&GroupCreateSop, &GroupCreateParams {
    name: "top_half".into(),
    entity: GroupEntity::Points,
    ..Default::default()
})?;

GroupCombineSop groups_sops

Inputs: 1

Combines two groups using boolean operations: union, intersect, or subtract. The result is stored in a new or existing group. 

let geo = geo.apply(&GroupCombineSop, &GroupCombineParams {
    group_a: "left".into(),
    group_b: "top".into(),
    operation: GroupOp::Intersect,
    result_name: "top_left".into(),
})?;
