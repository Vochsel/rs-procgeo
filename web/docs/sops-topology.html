Topology SOPs

SOPs that modify geometry connectivity, ordering, and structure.

Topology SOPs restructure how points and primitives are connected, ordered, or grouped — without changing positions (except Fuse, which merges coincident points). All take 1 input unless noted otherwise.

FuseSop topology

Inputs: 1

Merges coincident points that fall within a distance threshold. After merging, primitives referencing the removed points are updated to reference the surviving point. Useful for welding seams after merging separate meshes.

ParameterTypeDefaultDescription
distancef320.001Distance threshold for merging
 
// Weld seams after merging two meshes
let welded = merged.apply(&FuseSop, &FuseParams {
    distance: 0.01,
})?;

SortSop topology

Inputs: 1

Reorders points or primitives by axis value, reversal, or random shuffle. Sorting by axis is useful for spatial partitioning; random mode is useful for randomized rendering or processing order.

ParameterTypeDefaultDescription
entitySortEntityPointsPoints or Primitives
modeSortModeByAxisByAxis, Reverse, or Random
axisSortAxisYX, Y, or Z (for ByAxis mode)
seedu640Random seed (for Random mode)
 
// Sort points bottom-to-top by Y axis
let sorted = geo.apply(&SortSop, &SortParams {
    entity: SortEntity::Points,
    mode: SortMode::ByAxis,
    axis: SortAxis::Y,
    ..Default::default()
})?;

ReverseSop topology

Inputs: 1

Reverses the winding order of all polygon primitives, effectively flipping their normals. Useful when geometry appears inside-out or when you need to invert face orientation after a mirror operation.

ParameterTypeDefaultDescription
No parameters
 
let flipped = geo.apply(&ReverseSop, &ReverseParams::default())?;

ResampleSop topology

Inputs: 1

Resamples curves and polylines to uniform segment length. The input polyline is walked and new points are placed at intervals of length along the curve. A max_segments cap prevents runaway subdivision on very long curves.

ParameterTypeDefaultDescription
lengthf320.1Target segment length
max_segmentsu321000Maximum number of segments
 
let resampled = line.apply(&ResampleSop, &ResampleParams {
    length: 0.05,
    max_segments: 500,
})?;

ConnectivitySop topology

Inputs: 1

Labels each connected component of the geometry with a unique integer. The result is stored as a primitive attribute with the specified name. Useful for identifying separate islands after a Voronoi fracture or for per-piece processing.

ParameterTypeDefaultDescription
attrib_nameString"class"Name of the integer attribute to create
 
let labeled = fractured.apply(&ConnectivitySop, &ConnectivityParams {
    attrib_name: "class".into(),
})?;

BlastSop delete

Inputs: 1

Deletes elements that belong to a named group. By default, group members are removed; set negate to true to keep only group members and delete everything else. Works on either primitives or points.

ParameterTypeDefaultDescription
group_nameString""Name of group to blast
entityBlastEntityPrimitivesPrimitives or Points
negateboolfalseIf true, keep only group members
 
// Remove all faces in the "bottom" group
let blasted = geo.apply(&BlastSop, &BlastParams {
    group_name: "bottom".into(),
    entity: BlastEntity::Primitives,
    negate: false,
})?;

DeleteSop delete

Inputs: 1

Deletes elements by index range. All elements with indices in the half-open range [range_start, range_end) are removed. Operates on either points or primitives.

ParameterTypeDefaultDescription
entityDeleteEntityPrimitivesPrimitives or Points
range_startusize0Start index (inclusive)
range_endusize0End index (exclusive)
 
// Delete the first 10 primitives
let trimmed = geo.apply(&DeleteSop, &DeleteParams {
    entity: DeleteEntity::Primitives,
    range_start: 0,
    range_end: 10,
})?;

VoronoiFractureSop voronoi

Inputs: 2 (mesh, seed points)

Fractures a mesh using a 3D Voronoi diagram. Seed points are provided as the second input, and the geometry is split into convex cells by clipping along bisecting planes between each pair of seeds. A "piece" primitive attribute is created to identify each fragment. The cut_plane_offset shifts clip planes along their normals — positive values create gaps between pieces, negative values create overlap.

ParameterTypeDefaultDescription
cut_plane_offsetf320.0Offset cut planes along normals (positive = gaps, negative = overlap)
create_inside_facesbooltrueGenerate interior faces at fracture boundaries
 
// Scatter seed points, then fracture a box
let seeds = box_geo.apply(&ScatterSop, &ScatterParams { count: 20, seed: 42 })?;
let pieces = VoronoiFractureSop.execute(
    &[&box_geo, &seeds],
    &VoronoiFractureParams { cut_plane_offset: 0.02, ..Default::default() },
)?;
