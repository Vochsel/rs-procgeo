Transform & Reshape SOPs

SOPs that move, deform, and reshape geometry.

Transform and reshape SOPs take 1 input (unless noted otherwise) and return modified geometry. Chain them with .apply(&sop, &params).

TransformSop transform

Inputs: 1

Apply translate, rotate, and scale to all points. Transform order is: translate * pivot * rotate * scale * -pivot. Rotation is specified in degrees as XYZ Euler angles.

ParameterTypeDefaultDescription
translateVec3Vec3::ZEROTranslation offset
rotateVec3Vec3::ZERORotation in degrees (XYZ Euler)
scaleVec3Vec3::ONEScale factors
pivotVec3Vec3::ZEROPivot point
 
let moved = geo.apply(&TransformSop, &TransformParams {
    translate: Vec3::new(0.0, 2.0, 0.0),
    rotate: Vec3::new(0.0, 45.0, 0.0),
    scale: Vec3::splat(0.5),
    ..Default::default()
})?;

NormalSop normals

Inputs: 1

Computes area-weighted vertex normals using Newell's method. Creates a "N" point attribute with the Normal type qualifier. This SOP has no parameters — it always computes smooth normals from face topology.

ParameterTypeDefaultDescription
No parameters
 
let with_normals = geo.apply(&NormalSop, &NormalParams::default())?;

SubdivideSop reshape

Inputs: 1

Subdivides mesh faces. In Linear mode, each quad is split into 4 quads and each triangle into 4 triangles by inserting edge midpoints. In CatmullClark mode, the limit surface is approximated with smoothed vertex positions.

ParameterTypeDefaultDescription
depthu321Subdivision iterations
modeSubdivideModeLinearLinear or CatmullClark
 
let smooth = geo.apply(&SubdivideSop, &SubdivideParams {
    depth: 3,
    mode: SubdivideMode::CatmullClark,
})?;

PolyExtrudeSop reshape

Inputs: 1

Extrudes polygon faces along their normals. Each face is pushed outward by distance and optionally inset toward its centroid. Side quads bridge the original and extruded edges.

ParameterTypeDefaultDescription
distancef321.0Extrusion distance
insetf320.0Inset toward face centroid
output_frontbooltrueInclude front face
output_sidebooltrueInclude side quads
 
let extruded = geo.apply(&PolyExtrudeSop, &PolyExtrudeParams {
    distance: 0.5,
    inset: 0.1,
    ..Default::default()
})?;

SmoothSop reshape

Inputs: 1

Applies Laplacian mesh smoothing. Each iteration moves every point toward the average of its connected neighbours, weighted by strength. Multiple iterations produce progressively smoother results.

ParameterTypeDefaultDescription
iterationsu321Smoothing passes
strengthf320.5Smoothing factor per iteration
 
let smoothed = geo.apply(&SmoothSop, &SmoothParams {
    iterations: 5,
    strength: 0.8,
})?;

ClipSop reshape

Inputs: 1

Clips geometry by a plane defined by a point and normal. Polygons that straddle the plane are split, with new edges created along the clip boundary. Use keep_above to select which side of the plane is retained.

ParameterTypeDefaultDescription
originVec3Vec3::ZEROPoint on the clipping plane
normalVec3Vec3::YPlane normal direction
keep_abovebooltrueKeep geometry above (true) or below (false) the plane
 
// Cut a sphere in half at the origin
let half = sphere.apply(&ClipSop, &ClipParams {
    origin: Vec3::ZERO,
    normal: Vec3::Y,
    keep_above: true,
})?;

ScatterSop scatter

Inputs: 1

Randomly distributes points on the surface of mesh primitives. Points are distributed proportionally to face area, so larger faces receive more points. The output is a point cloud (no primitives).

ParameterTypeDefaultDescription
countu32100Number of points to scatter
seedu640Random seed for reproducibility
 
let points = grid.apply(&ScatterSop, &ScatterParams {
    count: 1000,
    seed: 42,
})?;

CopyToPointsSop copy

Inputs: 2 (source, target)

Instances the source geometry at each point of the target geometry. Each copy is translated to the corresponding point position. This is a multi-input SOP: the first input is the template, and the second provides the target points.

ParameterTypeDefaultDescription
No parameters
 
// Scatter trees on a terrain
let tree = generate(&BoxSop, &BoxParams::default())?;
let pts = terrain.apply(&ScatterSop, &ScatterParams { count: 50, seed: 0 })?;
let forest = CopyToPointsSop.execute(&[&tree, &pts], &CopyToPointsParams)?;

MergeSop merge

Inputs: 0..N

Concatenates multiple geometries into a single Geometry. Points, primitives, attributes, and groups from all inputs are combined. Primitive vertex indices are offset to account for merged point arrays.

ParameterTypeDefaultDescription
No parameters
 
let a = generate(&BoxSop, &BoxParams::default())?;
let b = generate(&SphereSop, &SphereParams::default())?;
let merged = MergeSop.execute(&[&a, &b], &MergeParams)?;
