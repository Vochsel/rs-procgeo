Creation SOPs

Generator SOPs that create new geometry from parameters.

Creation SOPs take 0 inputs — they are generators. Call them with generate(&sop, &params) rather than .apply(). All creation SOPs are gated behind the creation feature flag.

BoxSop creation

Inputs: 0 (generator)

Creates an axis-aligned box with 8 points and 6 quad faces. The box is centered at center with dimensions given by size.

ParameterTypeDefaultDescription
sizeVec3Vec3::ONEDimensions along each axis
centerVec3Vec3::ZEROCenter position
 
let cube = generate(&BoxSop, &BoxParams {
    size: Vec3::splat(2.0),
    center: Vec3::new(0.0, 1.0, 0.0),
})?;

GridSop creation

Inputs: 0 (generator)

Creates a rectangular grid of quads on the specified orientation plane. The grid is divided into rows × cols cells, producing (rows+1) * (cols+1) points.

ParameterTypeDefaultDescription
size[f32; 2][10.0, 10.0]Width and depth
rowsu3210Row divisions
colsu3210Column divisions
centerVec3Vec3::ZEROCenter position
orientationGridOrientationXZPlane: XZ, XY, or YZ
 
let floor = generate(&GridSop, &GridParams {
    size: [20.0, 20.0],
    rows: 50,
    cols: 50,
    ..Default::default()
})?;

SphereSop creation

Inputs: 0 (generator)

Creates a UV sphere with configurable latitude (rows) and longitude (cols) divisions. The radius parameter accepts a Vec3 allowing ellipsoid shapes.

ParameterTypeDefaultDescription
radiusVec3Vec3::splat(0.5)Radius per axis
centerVec3Vec3::ZEROCenter position
rowsu3212Latitude divisions (min 2)
colsu3224Longitude divisions (min 3)
 
let sphere = generate(&SphereSop, &SphereParams {
    radius: Vec3::splat(1.0),
    rows: 24,
    cols: 48,
    ..Default::default()
})?;

LineSop creation

Inputs: 0 (generator)

Creates an open polyline from origin along direction for the given length. The line is subdivided into points evenly-spaced samples.

ParameterTypeDefaultDescription
originVec3Vec3::ZEROStart position
directionVec3Vec3::YDirection vector
lengthf321.0Line length
pointsu322Number of points (min 2)
 
let line = generate(&LineSop, &LineParams {
    origin: Vec3::new(0.0, 0.0, 0.0),
    direction: Vec3::new(1.0, 1.0, 0.0).normalize(),
    length: 5.0,
    points: 10,
})?;

CircleSop creation

Inputs: 0 (generator)

Creates a circle or regular polygon as a closed polyline. With high divisions it approximates a smooth circle; low values produce regular polygons (e.g., 6 for a hexagon).

ParameterTypeDefaultDescription
radiusf321.0Circle radius
centerVec3Vec3::ZEROCenter position
divisionsu3240Segment count (min 3)
orientationGridOrientationXZPlane
 
// A hexagon on the XZ plane
let hex = generate(&CircleSop, &CircleParams {
    radius: 2.0,
    divisions: 6,
    ..Default::default()
})?;

TubeSop creation

Inputs: 0 (generator)

Creates a cylinder, cone, or tapered tube. Setting radius_top to 0.0 produces a cone. The caps parameter controls whether top, bottom, both, or no end-caps are generated.

ParameterTypeDefaultDescription
radius_bottomf320.5Bottom radius
radius_topf320.5Top radius (0 = cone)
heightf321.0Height
centerVec3Vec3::ZEROCenter
colsu3224Circumference divisions (min 3)
rowsu322Height divisions (min 2)
capsTubeCapNoneCap mode: None, Top, Bottom, Both
 
// A cone with a bottom cap
let cone = generate(&TubeSop, &TubeParams {
    radius_bottom: 1.0,
    radius_top: 0.0,
    height: 2.0,
    caps: TubeCap::Bottom,
    ..Default::default()
})?;

TorusSop creation

Inputs: 0 (generator)

Creates a torus (donut) shape. The radius_outer controls the distance from the center of the torus to the center of the tube, while radius_inner controls the tube thickness.

ParameterTypeDefaultDescription
radius_outerf321.0Major radius
radius_innerf320.3Minor radius
centerVec3Vec3::ZEROCenter
rowsu3212Ring divisions
colsu3224Tube divisions
 
let donut = generate(&TorusSop, &TorusParams {
    radius_outer: 2.0,
    radius_inner: 0.5,
    rows: 24,
    cols: 48,
    ..Default::default()
})?;
