Python API

Python usage via PyO3 bindings.

Installation

pip install procgeo

Or with uv:

uv pip install procgeo

Then import the module:

import procgeo

Geometry Object

All creation and manipulation functions return a Geometry object. It has a readable repr and the following properties and methods:

Property / MethodReturnsDescription
num_points int Number of points (property).
num_prims int Number of primitives (property).
num_vertices int Number of vertices (property).
point_pos(index) tuple[float, float, float] Position of a single point.
bounding_box() tuple[tuple, tuple] Returns ((min_x, min_y, min_z), (max_x, max_y, max_z)).
repr(geo) str Geometry(points=8, prims=6, vertices=24) 
import procgeo

geo = procgeo.create_box()
print(geo)                   # Geometry(points=8, prims=6, vertices=24)
print(geo.num_points)        # 8
print(geo.point_pos(0))      # (-0.5, -0.5, -0.5)
print(geo.bounding_box())    # ((-0.5, -0.5, -0.5), (0.5, 0.5, 0.5))

Creation Functions

All creation functions use keyword arguments with sensible defaults. Every parameter is optional.

create_box

procgeo.create_box(
    size_x=1.0, size_y=1.0, size_z=1.0,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create an axis-aligned box.

create_grid

procgeo.create_grid(
    rows=10, cols=10,
    size_x=10.0, size_y=10.0,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create a quad grid in the XZ plane.

create_sphere

procgeo.create_sphere(
    radius=0.5, rows=12, cols=24,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create a UV sphere.

create_line

procgeo.create_line(
    length=1.0, points=2,
    origin_x=0.0, origin_y=0.0, origin_z=0.0,
    dir_x=0.0, dir_y=1.0, dir_z=0.0
)

Create an open polyline along a direction.

create_circle

procgeo.create_circle(
    radius=1.0, divisions=40,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create a circle polygon.

create_tube

procgeo.create_tube(
    radius_bottom=0.5, radius_top=0.5, height=1.0,
    cols=24, rows=2,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create a cylinder, cone, or tube. Set radius_top=0 for a cone.

create_torus

procgeo.create_torus(
    radius_outer=1.0, radius_inner=0.3,
    rows=12, cols=24,
    center_x=0.0, center_y=0.0, center_z=0.0
)

Create a torus.

revolve

procgeo.revolve(
    geo,
    origin_x=0.0, origin_y=0.0, origin_z=0.0,
    axis_x=0.0, axis_y=1.0, axis_z=0.0,
    divisions=24, start_angle=0.0, end_angle=360.0,
    end_caps=False
)

Revolve a profile curve around an axis to create a surface of revolution.

create_metaball

procgeo.create_metaball(
    center_x=0.0, center_y=0.0, center_z=0.0,
    radius=1.0, weight=1.0,
    threshold=1.0, resolution=32,
    kernel="wyvill"
)

Create a metaball isosurface. Kernel options: "wyvill", "blinn", "hart".

Manipulation Functions

All manipulation functions take a Geometry as the first positional argument and return a new Geometry. The original is never mutated.

transform

procgeo.transform(
    geo,
    translate_x=0.0, translate_y=0.0, translate_z=0.0,
    rotate_x=0.0, rotate_y=0.0, rotate_z=0.0,
    scale_x=1.0, scale_y=1.0, scale_z=1.0,
    pivot_x=0.0, pivot_y=0.0, pivot_z=0.0
)

Translate, rotate (degrees), and scale geometry around a pivot.

compute_normals

procgeo.compute_normals(geo)

Compute area-weighted point normals. Stores result in the "N" point attribute.

merge

procgeo.merge(geometries: list)

Merge a list of Geometry objects into one.

subdivide

procgeo.subdivide(geo, depth=1)

Subdivide all faces. Each level quadruples face count.

scatter

procgeo.scatter(geo, count=100, seed=0)

Scatter random points on the surface of the geometry.

copy_to_points

procgeo.copy_to_points(source, target)

Instance source geometry at each point of target.

poly_extrude

procgeo.poly_extrude(
    geo,
    distance=1.0, inset=0.0,
    output_front=True, output_side=True
)

Extrude faces along their normals.

smooth

procgeo.smooth(geo, iterations=1, strength=0.5)

Laplacian smoothing.

clip

procgeo.clip(
    geo,
    origin_x=0.0, origin_y=0.0, origin_z=0.0,
    normal_x=0.0, normal_y=1.0, normal_z=0.0,
    keep_above=True
)

Clip geometry by an infinite plane.

reverse

procgeo.reverse(geo)

Flip polygon winding order.

resample

procgeo.resample(geo, length=0.1, max_segments=1000)

Resample curves to uniform segment length.

fuse

procgeo.fuse(geo, distance=0.001)

Merge points closer than distance.

connectivity

procgeo.connectivity(geo, attrib_name="class")

Label connected components with an integer primitive attribute.

color

procgeo.color(geo, r=1.0, g=1.0, b=1.0)

Set a uniform colour on all points ("Cd" attribute).

enumerate_attrib

procgeo.enumerate_attrib(geo, name="index", start=0)

Add a sequential integer attribute to each point.

measure_area

procgeo.measure_area(geo)

Compute the area of each primitive and store it as an attribute.

Example

A complete Python script that builds a procedural mesh pipeline and exports the result: 

import procgeo

# Generate a torus
torus = procgeo.create_torus(
    radius_outer=1.5,
    radius_inner=0.4,
    rows=16,
    cols=32
)

# Subdivide for a smoother surface
subdiv = procgeo.subdivide(torus, depth=1)

# Extrude the faces outward
extruded = procgeo.poly_extrude(subdiv, distance=0.1, inset=0.05)

# Smooth the result
smoothed = procgeo.smooth(extruded, iterations=2, strength=0.3)

# Add colour
colored = procgeo.color(smoothed, r=0.2, g=0.6, b=0.9)

# Compute normals for rendering
final = procgeo.compute_normals(colored)

# Inspect the result
print(final)
print(f"Points: {final.num_points}")
print(f"Prims:  {final.num_prims}")

bbox = final.bounding_box()
print(f"BBox min: {bbox[0]}")
print(f"BBox max: {bbox[1]}")

# Scatter points on the surface
pts = procgeo.scatter(final, count=500, seed=42)
print(f"Scattered {pts.num_points} points")

# Instance small spheres at scattered points
stamp = procgeo.create_sphere(radius=0.02)
instances = procgeo.copy_to_points(stamp, pts)

# Merge everything
merged = procgeo.merge([final, instances])

# Export
procgeo.write_obj(merged, "torus_pipeline.obj")
procgeo.write_glb(merged, "torus_pipeline.glb")

print("Exported!")
All functions are synchronous and execute the full Rust geometry pipeline in-process. The Geometry object is Clone-able on the Rust side, so passing it to multiple functions is efficient — no deep copies occur until the geometry is actually modified.
