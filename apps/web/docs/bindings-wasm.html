WebAssembly API

Browser-based usage via wasm-bindgen.

Building

The WASM binding lives in bindings/procgeo-wasm. Build it with wasm-pack: 

wasm-pack build bindings/procgeo-wasm --target web

This produces an ES module in bindings/procgeo-wasm/pkg/ ready to import with Vite, Webpack, or a plain <script type="module"> tag.

Loading

Import and initialise the WASM module before calling any functions:

import init, * as pg from 'procgeo-wasm';

await init();

// Now ready to use
const box = pg.createBox({ size: [1, 1, 1] });

Geometry Object

All creation and manipulation functions return a Geometry object with the following properties and methods:

Property / MethodReturnsDescription
numPoints number Number of points in the geometry (getter).
numPrims number Number of primitives (getter).
numVertices number Number of vertices (getter).
pointPos(index) Float32Array Position of a single point as [x, y, z].
boundingBox() { min: Float32Array, max: Float32Array } Axis-aligned bounding box corners.
getPositions() Float32Array All point positions as flat [x0,y0,z0, x1,y1,z1, ...].
getTriangleIndices() Uint32Array Fan-triangulated face indices for WebGL index buffers.
getNormals() Float32Array | undefined Point normals ("N" attribute) if present.
getColors() Float32Array | undefined Point colors ("Cd" attribute) if present.
toObj() string Serialize geometry as Wavefront OBJ text.
toGlb() Uint8Array Serialize geometry as binary glTF (GLB).

Creation Functions

All creation functions accept an optional params object. Omitted fields use Houdini-style defaults.

FunctionParamsDescription
createBox(params?) size: [x,y,z], center: [x,y,z] Axis-aligned box. Default size [1,1,1].
createGrid(params?) rows, cols, sizeX, sizeY, center: [x,y,z] Quad grid. Default 10x10, size 10x10.
createSphere(params?) radius, rows, cols, center: [x,y,z] UV sphere. Default radius 0.5, 12 rows, 24 cols.
createLine(params?) origin: [x,y,z], direction: [x,y,z], length, points Open polyline. Default length 1, 2 points.
createCircle(params?) radius, divisions, center: [x,y,z] Circle polygon. Default radius 1, 40 divisions.
createTube(params?) radiusBottom, radiusTop, height, cols, rows, center: [x,y,z] Cylinder/cone. Default radii 0.5, height 1.
createTorus(params?) radiusOuter, radiusInner, rows, cols, center: [x,y,z] Torus. Default outer 1.0, inner 0.3. 
// Create a box with custom size
const box = pg.createBox({ size: [2, 1, 1] });

// Create a sphere at a specific position
const sphere = pg.createSphere({
  radius: 0.5,
  rows: 16,
  cols: 32,
  center: [0, 1, 0]
});

// Default params are all optional
const grid = pg.createGrid();

Manipulation Functions

Manipulation functions take a Geometry as the first argument and return a new Geometry. The original is never mutated.

FunctionParamsDescription
transform(geo, params?) translate: [x,y,z], rotate: [x,y,z], scale: [x,y,z], pivot: [x,y,z] Translate, rotate, and scale geometry.
computeNormals(geo) — Compute area-weighted vertex normals (stored as "N" point attribute).
subdivide(geo, params?) depth, mode ("linear" | "catmullClark") Subdivide faces. Default depth 1, linear mode.
scatter(geo, params?) count, seed Scatter random points on surface. Default 100 points.
copyToPoints(source, target) — Instance source geometry at each point of target.
polyExtrude(geo, params?) distance, inset, outputFront, outputSide Extrude faces along normals. Default distance 1.
smooth(geo, params?) iterations, strength Laplacian smooth. Default 1 iteration, strength 0.5.
clip(geo, params?) origin: [x,y,z], normal: [x,y,z], keepAbove Clip geometry by a plane. Default clips above Y=0.
reverse(geo) — Flip polygon winding order.
color(geo, params?) color: [r,g,b] Set uniform point color ("Cd" attribute). Default white.
fuse(geo, params?) distance Merge coincident points. Default distance 0.001.
voronoiFracture(geo, points, params?) cutPlaneOffset, createInsideFaces Fracture geometry into Voronoi cells using external seed points. 
// Build a processing pipeline
const box = pg.createBox({ size: [2, 2, 2] });
const subdiv = pg.subdivide(box, { depth: 2, mode: "catmullClark" });
const moved = pg.transform(subdiv, { translate: [0, 1, 0] });
const result = pg.computeNormals(moved);

// Export as OBJ string
const objText = result.toObj();

// Export as GLB binary
const glbBytes = result.toGlb();

Three.js Integration

Convert ProcGeo geometry directly to a Three.js BufferGeometry using the typed array accessors: 

import * as THREE from 'three';
import init, * as pg from 'procgeo-wasm';

await init();

// Generate and process geometry
const geo = pg.createBox({ size: [1, 1, 1] });
const normals_geo = pg.computeNormals(geo);

// Build a Three.js BufferGeometry
const bufGeo = new THREE.BufferGeometry();
bufGeo.setAttribute(
  'position',
  new THREE.BufferAttribute(normals_geo.getPositions(), 3)
);
bufGeo.setIndex(
  new THREE.BufferAttribute(normals_geo.getTriangleIndices(), 1)
);

const normals = normals_geo.getNormals();
if (normals) {
  bufGeo.setAttribute(
    'normal',
    new THREE.BufferAttribute(normals, 3)
  );
}

// Optional: add vertex colors
const colors = normals_geo.getColors();
if (colors) {
  bufGeo.setAttribute(
    'color',
    new THREE.BufferAttribute(colors, 3)
  );
}

// Create mesh and add to scene
const mesh = new THREE.Mesh(
  bufGeo,
  new THREE.MeshStandardMaterial()
);
scene.add(mesh);
The typed arrays returned by getPositions(), getTriangleIndices(), getNormals(), and getColors() can be passed directly to Three.js BufferAttribute constructors with zero copies — they are views into WASM linear memory.

Full Browser Example

A complete pipeline: generate a torus, subdivide, compute normals, colour it, and render with Three.js: 

import init, * as pg from 'procgeo-wasm';
import * as THREE from 'three';

async function main() {
  await init();

  // Procedural pipeline
  const torus = pg.createTorus({
    radiusOuter: 1.0,
    radiusInner: 0.3,
    rows: 16,
    cols: 32
  });
  const subdiv = pg.subdivide(torus, { depth: 1 });
  const colored = pg.color(subdiv, { color: [0.3, 0.6, 1.0] });
  const final = pg.computeNormals(colored);

  // Convert to Three.js
  const bufGeo = new THREE.BufferGeometry();
  bufGeo.setAttribute('position', new THREE.BufferAttribute(final.getPositions(), 3));
  bufGeo.setIndex(new THREE.BufferAttribute(final.getTriangleIndices(), 1));
  const n = final.getNormals();
  if (n) bufGeo.setAttribute('normal', new THREE.BufferAttribute(n, 3));

  console.log(`Points: ${final.numPoints}, Prims: ${final.numPrims}`);
}

main();
