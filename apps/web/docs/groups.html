Groups

Named boolean selections of elements — for targeting SOPs and conditional processing.

Overview

Groups are named boolean membership sets attached to geometry elements. They are the primary mechanism for targeting SOPs — for example, passing a group name to BlastSop to delete only certain points, or to TransformSop to move only selected primitives. Groups auto-resize when elements are added (new slots default to false).

Group Types

TypeBackingDescription
Point groups BitVec One bit per point. Created with create_point_group.
Vertex groups BitVec One bit per vertex. Created with create_vertex_group on the GroupMap.
Primitive groups BitVec One bit per primitive. Created with create_prim_group.
Edge groups HashSet Set of (PrimHandle, edge_index) pairs. Sparse — only stores edges that are members.

Point, vertex, and primitive groups use bitvec for compact, cache-friendly storage. Edge groups use a HashSet because edges are identified by a (primitive, edge index) pair rather than a flat index.

ElementGroup API

ElementGroup is the bitset-backed structure used by point, vertex, and primitive groups. All three group types share this same API.

MethodSignatureDescription
new fn new(size: usize) -> Self Create a group with size bits, all initially false.
contains fn contains(&self, idx: usize) -> bool Test if an element is in the group.
add fn add(&mut self, idx: usize) Add an element to the group (set bit to true).
remove fn remove(&mut self, idx: usize) Remove an element from the group (set bit to false).
set fn set(&mut self, idx: usize, value: bool) Set membership explicitly.
count fn count(&self) -> usize Number of elements in the group (popcount).
size fn size(&self) -> usize Total capacity (number of bits).
resize fn resize(&mut self, new_size: usize) Grow or shrink the bitset. New bits default to false.
iter_set fn iter_set(&self) -> impl Iterator<Item = usize> Iterate over the indices of all set (true) bits.
clear fn clear(&mut self) Set all bits to false.

Boolean Operations

ElementGroup supports four boolean operations that modify the group in place. Because the underlying storage is bitvec, these operations work on whole machine words at a time for maximum throughput.

OperationMethodEffect
Union union(&mut self, &other) self |= other — adds all elements from other
Intersection intersect(&mut self, &other) self &= other — keeps only elements in both groups
Subtraction subtract(&mut self, &other) self &= !other — removes elements that are in other
Complement complement(&mut self) self = !self — flips all bits 
let mut a = ElementGroup::new(10);
for i in 0..6 { a.add(i); }       // a = {0,1,2,3,4,5}

let mut b = ElementGroup::new(10);
b.add(2); b.add(3); b.add(8);    // b = {2,3,8}

let mut u = a.clone();
u.union(&b);                      // u = {0,1,2,3,4,5,8}

let mut i = a.clone();
i.intersect(&b);                  // i = {2,3}

let mut s = a.clone();
s.subtract(&b);                   // s = {0,1,4,5}

let mut c = a.clone();
c.complement();                    // c = {6,7,8,9}

Geometry Group API

Groups are managed through the Geometry struct (convenience methods) and the underlying GroupMap (full API). The pattern is the same for all element types.

Point Groups

MethodDescription
geo.create_point_group(name) Create a new point group, sized to match the current point count.
geo.groups().point_group(name) Get an immutable reference to a point group. Returns Option<&ElementGroup>.
geo.groups_mut().point_group_mut(name) Get a mutable reference to a point group for adding/removing members.
geo.groups_mut().delete_point_group(name) Delete a point group. Returns true if it existed.
geo.groups().point_group_names() List the names of all point groups.

Primitive Groups

MethodDescription
geo.create_prim_group(name) Create a new primitive group, sized to match the current prim count.
geo.groups().prim_group(name) Get an immutable reference to a primitive group.
geo.groups_mut().prim_group_mut(name) Get a mutable reference to a primitive group.
geo.groups_mut().delete_prim_group(name) Delete a primitive group.
geo.groups().prim_group_names() List the names of all primitive groups.

Vertex & Edge Groups

Vertex groups follow the same pattern (create_vertex_group, vertex_group, vertex_group_mut, delete_vertex_group, vertex_group_names). Edge groups use a similar API but are backed by EdgeGroup (a HashSet<(PrimHandle, u8)>) instead of ElementGroup: 

// Edge groups store (PrimHandle, edge_index) pairs
let gm = geo.groups_mut();
gm.create_edge_group("boundary");

let eg = gm.edge_group_mut("boundary").unwrap();
eg.add(PrimHandle::from_index(0), 2);  // edge 2 of prim 0
eg.contains(PrimHandle::from_index(0), 2); // true

Usage Example

Create a point group based on a spatial condition, then use it with BlastSop to remove selected points: 

use procgeo::prelude::*;
use glam::Vec3;

let mut geo = generate(&BoxSop, &BoxParams::default())?;

// Create a group for points above y = 0.5
geo.create_point_group("top");
{
    let group = geo.groups_mut().point_group_mut("top").unwrap();
    for i in 0..geo.num_points() {
        if geo.point_pos(PointHandle::from_index(i)).y > 0.5 {
            group.add(i);
        }
    }
}

// Use with BlastSop to delete top points
let result = geo.apply(&BlastSop, &BlastParams {
    group_name: "top".into(),
    entity: BlastEntity::Points,
    ..Default::default()
})?;

Iterating Group Members

Use iter_set() to efficiently iterate over only the elements that are in the group, skipping unset bits: 

let group = geo.groups().point_group("top").unwrap();
for idx in group.iter_set() {
    let pos = geo.point_pos(PointHandle::from_index(idx));
    println!("Point {} is in group 'top': {:?}", idx, pos);
}
Auto-resize: When you add points, vertices, or primitives, all groups of the matching type are automatically resized. New elements default to false (not in any group).
